DELTA CATEGORIES:

1. SECTION HEADING CONVENTIONS [ENFORCED]
   - Field baseline (ECON) allows Roman or Arabic numerals.
   - EJW explicitly forbids all numbered divisions.
   - Constraint: Use bold centered (major) and bold left-aligned (subsections, if 2+) only.
   - Evidence: Author guidelines explicitly state "Numbers, letters, or Roman numerals should NOT divide sections."
   - Confirmed in spot-check: all 12 articles use bold headings; none use numbered divisions.

2. CITATION IN FOOTNOTES [ENFORCED]
   - Field baseline allows footnotes for supplementary material; citations go elsewhere.
   - EJW explicitly prohibits footnote citations.
   - Constraint: All citations must be parenthetic in text. Footnotes only for substantive remarks.
   - Evidence: Author guidelines: "Footnotes should not be used for citations."
   - Confirmed in spot-check: all articles use parenthetic citations; no citation footnotes observed.

3. DATA AND CODE AVAILABILITY LINKS [ENFORCED]
   - Field baseline does not mention data/code links.
   - EJW requires "links to all data and code, to ensure replicability" for statistical results.
   - Evidence: Explicit guideline; reflected in editorial mission (replicability focus).
   - Not confirmed in all 12 articles (some are non-empirical, non-statistical), but requirement is clear.

4. ABBREVIATION DENSITY [RELAXATION]
   - Field baseline describes "high" acronym density (estimator names, dataset names, concepts).
   - EJW advises "use sparingly; introduce complete names first."
   - Not a contradiction—deliberate dialing-back for accessibility.
   - Evidence: Author guidelines encourage plain-language clarity.
   - Confirmed in spot-check: sample articles use fewer unexplained acronyms than top-4 outlets.

5. STYLE REGISTER: DOWN-TO-EARTH VS. TECHNICAL [RELAXATION]
   - Field baseline prescribes "precise, technical, economical" register.
   - EJW explicitly encourages "a down-to-earth style that does not compromise scholarliness."
   - Tension: Accessibility vs. precision. Resolved by EJW editorial policy favoring clarity.
   - Evidence: Author guidelines; editorial process described as "like a carefully edited magazine."
   - Confirmed in spot-check: Magness & Makovi, Klein et al., Francis—all maintain rigor but use more expository prose.

6. CITATION FORMAT SPECIFICITY [GUIDELINE ONLY]
   - Field baseline: author-year format (parenthetical or in-text).
   - EJW: parenthetic format per Chicago 14th ed.; no in-text author embedded.
   - Not a delta per se (both prefer author-year); EJW mandates parenthetic specifically.
   - Evidence: Author guidelines reference Chicago 14th ed.

COMMON PITFALLS (JOURNAL-SPECIFIC)
----------------------------------
1. Numbered sections: Authors trained on top-4 ECON journals often use I., II., III. or
   1., 2., 3. This journal forbids it. Use bold headings only.

2. Citation footnotes: Temptation to place bibliographic citations in footnotes (standard
   in some fields). EJW prohibits this entirely. All citations must be parenthetic.

3. Missing data/code links: If article reports statistics, links are mandatory. Common
   omission for authors unfamiliar with this journal's replicability focus.

4. Unexplained jargon: EJW's "down-to-earth style" mandate differs from top-4 ECON journals.
   Define technical terms on first use even if field-baseline readers would infer meaning.

CONCLUSION
----------
Econ Journal Watch is a lower-tier journal with a critical, replication-focused mission.
Its style is less formal and more accessible than top-4 ECON outlets, reflecting its ABS 2 rating.
Main deviations from FIELD_SKILL are:
  1. Strict prohibition on numbered section divisions (vs. field openness).
  2. Strict prohibition on citation footnotes (vs. field flexibility).
  3. Mandatory data/code links (unique constraint).
  4. Deliberate relaxation of technical register and abbreviation density (accessibility first).

No field norms are contradicted; rather, EJW applies stricter constraints in some areas
(sections, footnotes, replicability) and looser constraints in others (formality, jargon).

This skill file is concise and Delta-focused, as appropriate for an ABS 2 journal where
most conventions follow FIELD_SKILL. It is immediately actionable for authors.
