MAJOR DELTAS FROM FIELD_SKILL
==============================

1. CITATION STYLE - CRITICAL DELTA (ENFORCED)
   - IJMFA uses numbered bracketed citations [1], [2], [3] ordered by appearance in text
   - FIELD_SKILL baseline uses author-date format "(Smith 2020)" or "Smith (2020)"
   - This is a major format conversion requirement; non-compliance triggers desk rejection
   - Impacts all in-text citations and reference list structure

2. HEADING STRUCTURE - EXPLICIT CONSTRAINT (ENFORCED)
   - Main headings: Arabic numerals (1, 2, 3) with no ALL-CAPS convention
   - Subheadings: 1.1, 1.2 format
   - Explicit prohibition on colons and dashes in heading text
   - FIELD_SKILL documents Roman vs. Arabic variance; IJMFA eliminates ambiguity

3. ABSTRACT - LESS STRUCTURED THAN BASELINE (RELAXATION)
   - IJMFA allows unstructured prose abstracts (up to 350 words)
   - FIELD_SKILL specifies "structured summary" (states research question, method, findings, contribution in single paragraph)
   - IJMFA relaxes structure requirement while maintaining content elements

4. WORD/PAGE LIMITS - NO EXPLICIT CONSTRAINT (RELAXATION)
   - IJMFA provides no public word or page limit
   - FIELD_SKILL baseline (ABS 4*/4 journals) typically has implicit 40–50 page norms
   - Observed practice shows wide variance in article length; no strict enforcement visible

5. HEADING TEXT - PROHIBITION ON PUNCTUATION (ENFORCED)
   - "No underlining, dashes, or colons in heading text" — explicit guideline
   - Standard practice in FIELD_SKILL allows colons in many journals (e.g., "Methodology: Data Sources")
   - IJMFA enforces simpler heading structures

FIELD_SKILL OVERRIDES
=====================
